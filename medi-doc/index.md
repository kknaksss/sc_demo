# 오로라 메디뷰티 도서관

## 이 도서관은

한국산 의료미용 주사제 3종(보툴리눔 톡신·HA 필러·스킨부스터)을 태국으로 수입·인허가·유통하는
**Aurora Medibeauty (Thailand) Co., Ltd.** 의 업무 문서 도서관입니다.

가치사슬: 제조사(다온바이오팜) → 유통사(오로라 메디뷰티) → 현지 클리닉 5곳. 마케팅은 서울글로우파트너스가 지원.
